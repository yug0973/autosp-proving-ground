Questions

          

            

              Which languages does it work with?
              
The pilot is for Python services hosted on GitHub.

            

            

              Which scanners does it take findings from?
              
Semgrep, CodeQL, Snyk Code and osv-scanner.

            

            

              Can it merge by itself?
              

                No. It opens pull requests with the evidence and stops there. Your reviewers approve and merge under
                your own branch protection, and the GitHub App can't change or bypass it.
              

            

            

              Where does my code run?
              

                In a throwaway container with no network, a read-only file system and a hard time limit. The
                container is gone when the job ends.
              

            

            

              What happens when it can't reproduce a finding?
              
No patch is written. The finding is closed as inconclusive.
