    Finding to follow

    It has to fail first.

    Before any fix is written, AUTOSP writes a test that exploits the finding and runs it against your code as it is. If the bug can’t be reproduced, no patch is written.

    Written where it can’t reach anything.

    A second agent writes the smallest fix it can, inside a throwaway container with no internet, a read-only file system and hard time limits. The container is gone when the job ends.

    Drag the sandbox to turn it, or focus it and use the arrow keys.

    Any one of three checks can send it back.

    The reproduction test has to pass now, your existing suite has to pass, and a fresh static scan has to come back clear. The agents can’t reach these checks. A fix that fails one goes back to the sandbox.

    Every merge is made by a person.

    AUTOSP opens a pull request with the evidence and stops there. Your reviewers approve and merge under your own branch protection, and the GitHub App can’t change or bypass it.
